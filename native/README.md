# Podcast Processor

Native app for Mac and iPad. It is a SwiftUI app, not a website inside a window.

1. Open `PodcastProcessor.xcodeproj` in Xcode.
2. For the Mac, choose **My Mac** and press Run.
3. For iPad, choose an iPad simulator or a connected iPad and press Run.
4. The first time, pick your Apple team under Signing if Xcode asks.

The scene is on the left. Foreground and Background are under it. Only the one you select can be dragged. Options scroll on the right.
